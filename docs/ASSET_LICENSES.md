## Photo-scan PBR textures — `apps/web/public/textures/`
Source: **ambientCG** (https://ambientcg.com), licence **CC0 1.0** (public domain; no attribution required, credited here anyway).
Each set was shrunk to 512 px, JPEG-compressed, and its colour map was brightness-normalised and partly desaturated so a material's own tint applies (`-c` colour, `-n` normal (OpenGL), `-r` roughness). Background: ADR-021.
